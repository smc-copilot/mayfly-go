# Casdoor 管理中心页面 Spec

> **版本：P1，配套实施计划 R3。状态：实施中。**
>
> 本文规定页面内容和交互。用户已要求按本规格实施；功能完成状态以测试和验收结果为准。

**目标：** 让管理员在 Mayfly 的独立 Casdoor 模块中完成连接配置、组织目录查看、用户管理和应用授权。未安装业务适配器、未关联业务实例时，全部核心页面仍可使用。

**适用范围：** 五个主页面及其详情、表单、预览、结果、范围设置和可选资源关联抽屉。本期不设计新建应用、用户/应用删除、密码重置、群组写入或即时业务会话注销。

## 1. 页面结构与统一交互

### 1.1 导航与默认入口

- 主导航名称“Casdoor 管理中心”，根路由 /casdoor，默认进入 /casdoor/applications。
- 五个子页面：连接管理、应用管理、用户管理、访问授权、操作记录；名称及地址与实施计划一致。
- 不增加 Octop 专用首页、服务器总览或业务实例导航。应用默认显示组织全部受管应用。
- 旧目录路径在登录及路由加载后重定向新应用页；无权限时显示既有无权限页，不能添加免登录例外。

### 1.2 公共页面区

自上而下：

1. 页面标题、当前连接选择器、组织和服务地址。
2. 目录状态栏：最后成功时间、最近尝试、同步结果；有权限时提供“立即同步”，另有“刷新页面数据”。
3. 当前页工具栏、筛选项、列表或工作区、分页。
4. 局部详情/编辑/预览/结果抽屉。

“刷新页面数据”只读 Mayfly 当前快照；“立即同步”触发远端只读采集，两者文案及行为分开。

连接管理列表展示全部可见连接，不受当前连接选择器的单连接过滤；其余四页严格限制当前 connectionId。没有选择连接时不请求全组织默认数据。

### 1.3 连接上下文与路由

- 当前连接及筛选保存在当前会话；URL 可携带 connectionId、appSnapshotId、userSnapshotId、operationId 和筛选条件，不携带密钥/草稿内容。
- 每个参数都重新校验权限和所属连接；无效或无权连接显示明确状态，不能静默切到另一组织。
- 切换连接时清空应用/用户选择、表格勾选、分页、预览与旧错误；旧请求晚返回不更新新连接内容。
- 编辑或预览尚未提交时，切页/切连接/关闭提示是否放弃草稿。已发送的操作保留服务器记录，不因离页取消或另起一次提交。
- 无连接：显示“尚未配置 Casdoor 连接”；有创建权限提供配置入口。只有无可见范围时显示“没有可访问的连接”，不能假装服务器没有数据。
- 页面刷新后可按 operationId 查看原操作；不能自动执行旧预览。
- 草稿只存在当前页面内存，密钥不写入 URL、会话存储或持久缓存；取消编辑后清空临时密钥。

### 1.4 表格、时间与适配

- 列表复用现有 DataTable、RowActions、表单和抽屉组件；分页沿用系统默认每页数量，缺省 10，不能通过固定请求 200 条冒充全量。
- 默认列表按名称升序，操作记录按创建时间倒序；搜索按查询按钮或 Enter 提交，改变筛选回第一页。
- 文本长值省略并支持查看/复制完整值；状态同时显示文字，不仅用颜色区分。
- 原始时间由接口返回带时区时间，页面沿用系统时区；验收使用 Asia/Shanghai，详情明确显示时区。
- 1024px 与 1440px 宽度下布局可用；更窄屏幕工具栏换行、抽屉占满可用宽度、表格局部横向滚动。使用 Flexbox，不改全局导航或固定计算页面高度。
- 图标使用 SvgIcon，支持现有明暗主题；全部展示文案通过中英文 i18n，实体名称保持原值。

## 2. 状态、权限与数据含义

### 2.1 状态必须分开

- **目录同步**：未同步 / 同步中 / 成功 / 失败 / 使用上次成功数据。
- **源对象存在性**：源端存在 / 最近完整同步未发现；同步失败不能把对象标为已删除。
- **账号状态**：启用 / 禁用 / 未知；只从可靠的 isForbidden 等字段转换。
- **应用登录状态**：允许登录 / 已关闭登录 / 未知；字段映射基于 disableSignin，不将“应用存在”当启用。
- **受管状态**：未接管 / 初始化未完成 / 已接管 / 发生漂移 / 能力不支持。
- **角色成员**：是 / 否 / 未核实；不是“能否登录”的同义词。
- **策略判定**：允许 / 拒绝 / 未核实；显示评估时间和依据，不声明完整登录条件已满足。
- **操作结果**：待确认 / 已验证 / 无需变更 / 失败 / 结果未知。预览过期另行标记，不混为远端操作失败。

空值显示“未获取”或“—”，不能显示 0、成功或启用。旧成功数据可继续查看，但必须带最后成功时间和失败原因。

### 2.2 页面与动作权限

- 无页读取权限：不显示菜单，直接 URL 按既有无权限流程处理；后端仍校验。
- 有页面读取权限但缺动作权限：隐藏对应写操作；详情仍可读。
- 有动作权限但连接只读或能力不支持：按钮禁用，并显示具体原因。
- 连接/范围设置、用户管理、账号启停、应用编辑、访问授权、审计分别使用实施计划中各自权限码。
- 可选资源关联还需对应资源操作权限；Casdoor 授权本身不依赖机器权限。
- 任意一步服务端返回 403：停止当前提交，保留非敏感输入并提示权限变化，不能换旧 API 重试。

## 3. 连接管理页面

### 3.1 列表与动作

列：名称、服务地址、组织、凭证状态、管理写入开关、最近同步结果、最后成功时间、操作。

筛选：名称/组织关键词。行操作：设为当前连接、详情、编辑连接、测试读取、立即同步、账号范围。新建入口仅系统管理员可见；范围入口仅有范围管理权限的系统管理员可见。本期不提供删除连接。

详情：应用、用户、角色/群组/权限的分项状态、数量、最近尝试/成功时间、错误原因、能力说明。应用结果为零时展示查询组织及 Owner 范围，方便区分真实为空和筛选错误。

### 3.2 连接表单

以分组表单展示，名称和含义如下：

- 名称：必填，去首尾空白，最多 64 字符。
- 服务地址：必填，最多 255 字符，HTTP/HTTPS 完整根地址，不含账号密码、查询参数或片段。
- 组织：必填，最多 64 字符；表示管理范围，不是应用名称。
- 管理 Client ID：必填，最多 128 字符；帮助文字说明用于后端 API 管理。
- 管理 Client Secret：新建/更换 Client ID 时必填；编辑原身份可留空表示不变。输入框不回填真实密钥，也不把“已配置”当作输入值。
- 超时：整数秒，默认 15，范围 1–120。
- 同步周期：整数秒，默认 3600，最小 60；说明调度器每 60 秒检查到期任务，不保证精确秒点。
- 校验 TLS：默认开启；HTTP 地址下标为不适用，不让开关产生“HTTP 已加密”的暗示。
- 管理写入：默认关闭。按动作区分协议支持、读取测试与生产写权限；相同版本隔离契约已验证且原目标读取通过后，有权限管理员可显式开启。读取测试不自动开关；生产写权限未实测时明确显示，不要求先做生产写探针。
- 高级应用 Owner 查询范围：可选，兼容旧 AppOwner；明确它是对象 Owner。设置后页面显示“目录已按 Owner 筛选”，不能标为组织全应用。实际版本无法完整列举时显示范围受限原因。

**连接身份保护：** 已保存连接的服务地址和组织只读；需要指向其他服务/组织时通过“新建连接”完成，不复用旧快照或业务引用。管理 Client ID 可在原服务/组织内轮换，但必须重新输入密钥。此规则须由后端同时校验。

底部：取消、测试读取、保存。测试不保存表单、不做任何远端写探针；已保存原目标可使用已存密钥。成功测试展示分项结果，失败保留表单并标出原因。测试从未输入密钥的新连接应提示必填，而非泛化为网络失败。

### 3.3 账号范围抽屉

列出可见范围：Mayfly 账号、显示名称、范围（只读/管理）、移除动作；管理员可添加账号及选择范围。账号选择使用已有 /sys/accounts/simple 的基础账号接口，通过模块 Api 封装调用，不复制完整账号模块。

说明：这里分配的是 Mayfly 管理权限，不是 Casdoor 业务用户访问权限；管理范围仍需要相应动作权限。系统管理员内置访问不能被误删。保存是本地管理配置，不调用 Casdoor 用户/授权写接口。

## 4. 应用管理页面

### 4.1 列表

筛选：关键词（名称、显示名、owner/name）、登录状态、受管状态、源存在性。默认包含源端存在的全部应用；历史缺失项可显式查看。

列：显示名/名称、Owner、组织、Client ID、登录状态、受管状态、最后同步时间、操作。无业务适配器时不增加空的实例列，也不按是否关联资源筛选。

行操作：

- 详情：具备读取权限即可。
- 编辑：只编辑本期允许字段，进入共享变更流程。
- 访问授权：跳转 /casdoor/access，携带当前连接和应用 ID。
- 关联资源：只在存在适配器时提供，进入通用资源抽屉。

本期不显示“新建应用”“删除应用”“导出密钥”或通用“创建资源”按钮。

### 4.2 详情和编辑

详情标签：

- 基本资料：真实 owner/name、显示名、组织、Client ID、首页、回调地址、登录状态。
- 授权概况：受管角色/权限标识、状态、已核实来源、策略评估说明；不能用组织用户总数充当可登录人数。
- 关联资源：可选，有适配器才出现，按资源可见性展示。
- 同步信息：存在性、最近成功/尝试时间、错误和数据来源。

编辑字段：显示名称（非空、最多 128）、首页地址（可空、合法 HTTP/HTTPS URL）、回调地址（多行非空项去重，按真实版本支持协议校验，不强制全部 HTTPS 以免破坏原生客户端）、允许登录（对应 disableSignin 的反向值）。

owner/name、组织、Client ID 只读；没有 Client Secret 字段。回调地址/登录状态变化在预览中突出显示对该应用认证的影响。源已缺失、数据不完整或能力不支持时禁止编辑并说明原因。

## 5. 用户管理页面

### 5.1 列表与详情

筛选：用户名/显示名/邮箱关键词、账号状态、源存在性。列：用户名、显示名、邮箱、组织、账号状态、源稳定 ID（可在详情完整查看）、最后同步时间、操作。

动作：详情、新建用户、编辑资料、启用/禁用账号、查看应用访问。新建只在激活路径已验证且具备动作权限/管理范围时启用，否则展示禁用原因。

详情标签：

- 基本资料：SourceId、API ObjectId、用户名、资料、组织、状态及来源时间。
- 应用访问：用户与各应用的受管角色成员关系、已评估策略与时间；点击单项打开授权页。
- 同步信息：存在性、错误及最近成功时间。

同名用户不得合并；本页不显示业务系统内部用户 ID，也不自动按邮箱建立业务身份关联。

### 5.2 表单与启停

新建：用户名、显示名、邮箱；组织固定为当前连接。用户名必填、最多 128、保持大小写、不得含路径分隔符；显示名必填、最多 128；邮箱可空，非空校验格式、最多 254。其他部署端规则由能力/服务端错误反馈，不猜测密码策略。无密码/管理员字段。

编辑：只允许显示名、邮箱；用户名、SourceId、组织只读。

启停：显式选择“禁用组织账号”或“启用组织账号”，进入预览，不使用点击即生效的行内开关。预览显示影响该组织所有应用；操作不表述为某个应用撤权，也不承诺注销所有业务会话。

创建保存与首次激活/首次登录是不同结果；成功后显示账号已建立及已核实的激活方式，不自动标记已能登录全部应用。

## 6. 访问授权页面

### 6.1 授权工作区

顶部为当前连接及应用选择器；应用选择来自分页/搜索接口，不固定截断。没有应用时提示先同步目录；不得要求先建业务实例。

应用选择后，显示登录状态、受管状态、模型能力及源更新时间。页面标签：

- 用户访问：用户列表与角色成员情况，支持勾选和授予/撤销。
- 角色：只读列表，显示名称、用户/嵌套角色及来源。
- 群组：只读列表，显示名称、成员证据及来源。
- 权限：只读列表，显示资源类型/资源、动作、效果、模型、启停及审批状态。

标签里的角色/群组/权限是该组织可读的授权依据，列表要区分是否明确关联当前应用；无法判断的不能静默过滤掉。对象详情用白名单字段，不提供任意 JSON 编辑器或“保存权限”按钮。

### 6.2 用户选择与授予/撤销

用户列表列：用户名、显示名、本系统角色成员（是/否/未核实）、策略判定、评估时间、操作。默认是组织用户分页投影；未评估策略显示“未核实”，不批量伪造允许/拒绝。

- 筛选：关键词、受管角色成员状态。查看访问依据调用单用户/应用评估接口。
- 勾选仅对显式选择生效；换页、改筛选或换应用清空选择。本期单次最多 100 个用户，前后端同时限制。
- 未接管应用：提供“初始化应用访问管理”；预览现有规则、默认允许及所选初始用户，明确它可能改变非所选用户的新登录资格。
- 初始化未完成/规则漂移/能力不支持：禁用成员写入，显示具体阻断项；保留读取与查看操作记录。
- 已接管：提供“授予访问”和“撤销本系统授予”，进入共享变更流程。
- 已是成员再授予，或非成员再撤销，可返回无需变更；不能因为角色没变就把完整访问结果标为已拒绝。
- 查看依据展示直接权限、角色、群组、管理员例外或默认规则，时间及尚未核实条件。

使用复选框选择已知用户；不提供“选中所有未加载账号”或一次性全组织授权按钮。

### 6.3 授权文案

撤销预览固定包含：“此次仅撤销本系统维护的授权。用户仍可能通过其他权限来源访问；已有业务会话按业务系统策略处理。”此句作为中英文国际化文本，不硬编码进组件。

有效策略即使允许，也不能显示“所有登录条件已通过”；缺少上下文或无法解释模型时显示原因，而非弹通用失败框后丢失选择。

## 7. 共享变更抽屉：编辑 → 预览 → 结果

适用于用户新建/编辑/启停、应用编辑、初始化/授予/撤销。连接本地保存和范围本地保存不走远端变更流程。

### 7.1 编辑和预览

- 编辑步校验字段；“查看变更”调用 preview，绝不写远端。
- 预览包含：操作、服务/组织、对象稳定标识、逐字段前后值、用户清单、影响范围、原因/警告、阻断项、有效期倒计时。
- 可选显示当前操作者可见的关联资源，注明只覆盖已登记可见资源；资源适配器不可用不阻断 Casdoor 自身授权。
- 有阻断项时“确认执行”禁用。到期后禁用，提供“重新预览”；修改编辑内容使旧 previewId 失效。
- 前后值只展示白名单字段，不展示 Client Secret、密码、令牌或完整原始响应。
- 空初始用户集合的初始化预览，须明确提示可能形成空白名单；不自动选择全部组织用户。单用户编辑/启停只能有一个目标，不能误用批量授权的用户数组。

### 7.2 执行与结果

- 确认提交只发送 previewId、connectionId、幂等键；同一尝试复用同键，不因双击/网络返回慢生成新操作。
- 执行期间禁用重复提交，显示“正在执行并核对”，不能立即弹“保存成功”。
- verified：显示“变更已回读验证”，并独立呈现成员/策略结果。
- noop：显示“无需变更”，保留现状及判定。
- failed：显示分项原因及哪些步骤已经生效。用户修正后生成新预览，不能自动补写未知步骤。
- pending/unknown：显示“结果待确认/结果未知”，提供操作编号和“核对结果”，禁止直接再次执行原命令。
- 部分成功不当作全部成功；保留分项远端结果和核实状态。
- 整体状态按实施计划归并：执行中为 pending；结束后有未知则 unknown，否则有失败则 failed，全 noop 才为 noop，其余全已核实才为 verified。有成功分项的 failed 显示“部分完成”，不声称已回滚。非授权操作不渲染无意义的成员/访问结论。
- 结果抽屉保持打开，由用户关闭；打开后刷新对应列表和操作记录，但不会把本地草稿当源快照。
- GET 操作结果可每 3 秒轮询，最长 60 秒；随后停止自动轮询。轮询只读取已存记录。显式“核对结果”调用只读远端回读接口，不进行任何远端修改。关闭抽屉、切换连接或退出登录均停止轮询，旧请求不更新新上下文。

复杂变更使用专用 ChangeWorkflow 抽屉管理状态；AutoForm 复用字段与校验，不能套用“HTTP 成功即自动提示保存成功并关闭”的默认提交流程处理 pending/unknown。不修改公共表单接口。

## 8. 操作记录页面

筛选：时间范围、动作、状态、操作者关键词、目标关键词；默认当前连接最近 7 天，可改起止，按创建时间倒序。预览记录与执行记录分开：默认只看已提交操作，可选择显示未提交/过期预览。

列：操作编号、时间、操作者、动作、目标摘要、状态、验证时间、操作。支持查看，不提供批量删除或清空审计。

详情：原连接/组织、目标稳定 ID、脱敏差异、每步执行与回读结果、错误原因、幂等重放标记、关联 previewId、时间、会话影响。仅有审计读取权限时可看结果，但不能触发需要原管理动作权限的“核对结果”。

管理者有原动作权限和连接管理范围时可对 pending/unknown 操作显式核对；核对不再次写远端。失败后修改重提必须经过新预览，旧操作证据保留。

## 9. 可选关联资源抽屉

- 由应用页按可用适配器打开；通用字段为系统、资源名称/标识、访问地址、当前关联状态。
- 选择系统后分页搜索当前账号可操作资源；系统未注册或无资源权限时显示对应原因。
- 关联前展示应用 owner/name、组织、目标资源、该资源原有关联；覆盖已有绑定须明确确认，解绑须显示将移除的引用。
- 关联只修改目标系统的元数据，不能暗示已配置其 OIDC 或授予 Casdoor 权限。
- 没有适配器时不显示空的“实例管理”区域。详情和关联失败不影响用户继续查看/管理 Casdoor 应用。
- 业务内部身份映射仍在相应业务页面；核心不出现 Octop 专属字段。

## 10. 异常、空数据与能力缺失

- 网络失败且有旧快照：保留列表，局部错误和最近成功时间，不用全屏空白替代。
- 网络失败且没有快照：错误状态及重试，不显示“暂无用户/应用”作为成功空列表。
- 读取成功确实为空：显示正常空状态、当前组织/筛选及同步入口。
- 查询条件无结果：显示“没有匹配结果”和重置筛选。
- 部分目录不可读：分项标出，已成功部分仍可读；相关写功能按能力/最新源状态限制。
- 409 源状态变化：保留输入，提示重新预览；不能沿用旧快照强行保存。
- 源对象不存在：保留审计和历史快照，阻止修改该对象，不本地伪造“删除成功”。
- 密钥错误：只提示认证问题与更换凭证入口，不回显服务端原始认证头。
- 能力不支持：明确“不支持/未验证及原因”，不把按钮显示为已成功配置，也不要求必须关联业务实例。
- 首次真实业务写入被 401/403 拒绝：记录失败，提示当前凭证对应动作被拒绝并禁用继续提交；凭证/权限更新并重新核查前不自动重试或切换身份。

## 11. 页面所需 API 和响应补充

这些是页面可落地的必要契约，需同步进实施计划：

- 连接列表/详情返回可见身份、凭证已配置标记、当前账号范围、managementEnabled、各分项同步、按动作能力及阻断原因；不返回密钥。
- 按动作能力区分 protocolCapability（supported/unsupported/unverified）、readProbe（passed/failed/unverified）、writeAuthorization（allowed/denied/unverified），显示“写权限未实测”不能被前端替换为“已验证”。
- 本地应用/用户/对象列表支持页面列出的过滤、pageNum/pageSize 与总数；应用/user 详情补充本期可见资料，不以菜单显示所需字段推导隐藏数据。
- GET /casdoor/objects/:id?connectionId=：返回当前连接下单个对象的白名单投影和来源时间；ID 与连接不一致时拒绝，不静默查询其他组织。
- GET /casdoor/access/subjects：{connectionId,appSnapshotId?,userSnapshotId?,keyword,membership,pageNum,pageSize}。必须且只能选应用或用户一侧：应用侧返回组织用户行，用户侧返回该用户的组织应用行；无本地业务实例条件。
- AccessSubjectRow：应用/用户引用、managedMembership（member/not_member/unknown）、decision（allowed/denied/unknown）、reasonCodes、evaluatedAt。未做可靠评估时 decision=unknown。
- POST /casdoor/operations/:id/reconcile：只回读远端并更新操作核实结果，不重新执行原写命令；检查当前操作者具有原动作权限及该连接管理范围，返回 OperationResult。只有审计读取权限不能触发。
- 本地保存连接拒绝修改已保存 serverUrl/organization；新服务/组织通过新连接管理。Client ID 轮换必须新密钥。
- preview/execute 后端校验最多 100 个显式用户；服务端指纹、目标、动作/范围检查不以页面状态代替。
- 分组投影、详情、能力和审计只返回白名单字段；远端业务错误返回稳定 reasonCode 和可国际化原因，不依赖中文 msg 字符串分支。

## 12. 页面验收场景

- UI-01：无业务模块/适配器，进入应用、用户和授权页，能管理未关联资源的应用。
- UI-02：无连接与无可见连接分别显示正确状态；普通账号不能看到新建/范围设置。
- UI-03：编辑原连接留空密钥可测试；页面不回显密钥；改 Client ID 必须新密钥；已保存服务/组织只读。
- UI-04：切换连接后旧慢请求不覆盖新页；用户/应用选择和预览均清空，无跨组织混显。
- UI-05：分页读取超过 200 个应用仍可检索/选择后续数据；非 Octop 应用不被过滤。
- UI-06：用户资料、组织禁用、单应用撤权为不同动作；禁用预览显示组织级影响。
- UI-07：批量最多 100 个显式用户；换页清空选择，无隐藏“全选全部”。
- UI-08：预览不写远端；过期/源变化须重新预览；执行双击不重复写。
- UI-09：unknown/pending/部分失败不显示普通保存成功；核对结果不发写请求。
- UI-10：撤销受管角色后有外部授权，页面展示剩余来源，不宣称彻底禁止登录。
- UI-11：成功空列表、筛选无结果、失败无快照及失败有旧数据的页面表现分别正确。
- UI-12：只读账号不可写，能力不支持有禁用原因；直达 API 仍被服务端拒绝。
- UI-13：无适配器无空实例区；有适配器但无机器权限，Casdoor 授权仍可用，资源详情和绑定按自身权限受限。
- UI-14：用户详情应用访问、对象详情、操作追踪能完成闭环；只有审计读取权限不能触发核对。
- UI-15：中英文、明暗主题、1024px/1440px、键盘提交/关闭可用；不存在裸 i18n key 和全页面横向溢出。
